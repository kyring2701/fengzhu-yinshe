# 🍃 关于枫竹音社 
 
这里是枫竹音社。
 
在这里，水平不分高下，爱好不受局限。无需精通乐理，不必身怀绝技，只要心怀对音乐的热忱，便可共赴这场永不落幕的音律盛景。
 
枫竹音社自创立至今，已稳步运营一年有余，社团现有成员一百五十余人。社群氛围包容多元，人才结构层次丰富，既有深耕乐域、技艺精湛的专业前辈坐镇引领，亦有满怀热爱、从零起步的入门新人逐梦同行。
 
本社为线上音乐合作社团，具备灵活自由的创作与协作模式：社员可随心自发发起合作企划、自主选定演奏曲目、自由组队编排演绎，不受线下时空束缚，不受演奏水平限制。社团曲风兼容并蓄，过往已成功排演JPOP、JROCK、吹奏乐等多类型作品，积累了成熟的线上合奏、分轨录制与后期合流经验。
 
未来，音社将依托现有创作基础，在每一位同好的参与与共创下，持续拓展曲风边界，探索更多音乐领域，打造自由度高、包容性强、专业性兼具的线上音乐交流平台。
