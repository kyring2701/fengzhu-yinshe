# 🎹 曲の推薦

演奏したい曲がありますか？お気に入りの曲を推薦して、みんなで合奏しましょう！

## 📝 推薦方法

1. 下のリンクをクリックして、推薦フォームを開きます。
2. 曲名、原作者、スタイル／ジャンルを記入します。
3. その曲を演奏したい理由を簡単に説明します。
4. 送信後、皆さんの選択に基づいてプロジェクトを計画します！

## 🎵 推薦の要件

- 曲風不問：ACG、吹奏楽、管弦楽、ロック、ジャズ、すべて歓迎。
- 難易度不問：簡単な小編成から大編成まで。
- 著作権注意：非営利の合奏練習のみを目的とします。
