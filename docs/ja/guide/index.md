# 📋 オンライン合奏ガイド

> 演奏者の皆様へ

楽団の皆さん、こんにちは！

異なる場所で録音された演奏を、美しく感動的な交響曲にまとめ上げるためには、高品質な原音録音が不可欠です。ご心配なく、プロ仕様の機材は必要ありません。必要なのはスマートフォンと少しの忍耐だけです。以下のガイドを必ず注意深く読み、従ってください。これによりミキシングエンジニアの作業時間を大幅に節約し、最終作品のクオリティを直接左右します。

## はじめに：ミキシングエンジニアへの提言

1. **音程とリズム**は、すべての演奏家にとって最も基本的な基礎力であり、楽団において最も基本的かつ最も重要な要求です。オンライン合奏においては、リズムのずれや音程の外れはさらに大きく拡大されてしまいます。そのため録音の際は、メトロノームをよく聴き、演奏のすべての拍が正確にクリックに合っていることを確認してください。徐々に速く／遅くなる自由なリズムについては、編曲者と演奏者が事前に相談し、DAWでテンポオートメーションを作成し、完全なメトロノーム音声を書き出して、それを用いて練習するようにしてください。また、複数の楽器が同時に速いパッセージを演奏する箇所は極力減らし、主旋律や速い音符の多いパッセージは基礎力のしっかりした演奏者に割り当て、弱起、フェルマータ、音の終わり、速いパッセージなどの正確なタイミングを事前に取り決め、弱起などの音の頭と終わりが揃うようにしましょう。

2. **セクションごとの分割録音は極力避け**、最初から最後まで一発で通して録音するのがベストです。どうしても分割録音が必要な場合は、該当セクションの具体的な情報を明確にしてください。例えば、ファイル名の変更（小節番号、第X～Y小節と明記）、録音の冒頭または末尾での口頭による小節番号の読み上げなど、ポストプロダクションでのセクション確認を容易にする工夫をしてください。

## 第一部：録音前の準備

### 1. 静かな部屋を選ぶ
- 騒音を発する可能性のある電化製品（エアコン、扇風機、冷蔵庫、携帯電話の着信音）をできるだけすべてオフにします。
- 部屋の窓やドアがしっかり閉まっていることを確認し、車の走行音や風の音などの環境騒音を減らします。
- 事前に家族やルームメイトに伝え、録音中に邪魔が入らないようにします。

### 2. ドライな音を確保する
- がらんとしてエコーのある部屋（例：未内装のリビング、バスルーム）での録音は避けてください。残響は録音の「最大の敵」であり、後処理での除去が非常に困難です。
- **最適な場所**：寝室、書斎、あるいは家具やカーテン、カーペットが多いリビング。これらの柔らかい物体は効果的にエコーを吸収し、音をよりクリーンにしてくれます。洋服タンスや洋服がたくさん掛かっている場所に向かって録音するのも良い方法です！
- **応急処置**：もしやむを得ず、がらんとしてルームリバーブの多い部屋で録音しなければならない場合は、部屋内の共振しない雑貨をすべて一つの隅に積み上げ、それを背にして演奏してください。同時にマイクをできるだけ音源に近づけ、上から楽器本体に向けて配置することで、最もクリーンな直接音を最大限に収録できます。

### 3. スマートフォンを固定する
- スマートフォンを手で持って録音しないでください。手の微細な動きが音に影響を与えます。
- スマートフォン用三脚や卓上スタンドを使用するか、スマートフォンを数冊の本に立てかけるなどして、安定して動かないようにします。

### 4. 統一された基準音を使用する
- 全体責任者が基準音Aの周波数を指定します。楽器の音程が正しいことを確認し、曲の前後にもこの基準音を演奏しておくと、ポストプロダクションでの音程校正に役立ちます。

## 第二部：録音設定

### 1. マイクの清浄度を確保する
- 録音前に、スマートフォンのマイクが清潔で、埃が詰まっていないか確認します。必要に応じて、柔らかい歯ブラシや細い綿棒でマイクを軽く拭いてください。

### 2. スマートフォンのマイク位置を知る（iPhoneを例に）
- **本体下部**：スマートフォンの下部、充電口やスピーカーのそばに、通常1～2つのマイクがあります。標準のボイスメモや一般的な録音アプリ、ハンズフリー通話時にはこの側のマイクが使用されます。
- **本体背面**：スマートフォンの背面、リアカメラとLEDフラッシュの間にある小さな穴が背面マイクです。リアカメラでのビデオ撮影時にこの側のマイクが使用されます。
- **画面上部**：iPhoneの画面上部、スピーカー付近にマイクが隠されています。フロントカメラでのビデオ撮影時やビデオ通話時に使用されます。

### 3. スマートフォン設定を調整する
- 必要であれば、**機内モードをオンにする**ことを推奨します。突然の電話や通知音が最高のテイクを台無しにするのを防ぎます。

### 4. 高品質な録音アプリを使用する
- スマートフォン標準搭載のボイスメモや、どこにでもあるような「レコーダー」アプリは避けてください。録音品質が低いだけでなく、ファイルサイズを優先して音質が犠牲になっていることが多いです。
- **推奨アプリ**：
  - Shure MOTIV Audio（iOS/Android）
  - GarageBand（iOS）
  - これらはロスレス形式での録音が可能です。

### 5. オーディオ形式、サンプルレート、ビットレートを設定する
設定可能な場合は、以下に統一してください：
- **形式**：WAV
- **サンプルレート**：48000Hz（最低44100Hz）
- **ビット深度**：24bit（最低16bit）
- **チャンネル数**：モノラル／ステレオ

### 6. ヘッドホンとメトロノーム
- 別のスマートフォン、またはヘッドホンに接続できるメトロノームを使用し、密閉型ヘッドホンに接続します。ヘッドホンを装着し、指定された速度でメトロノームを再生しながら演奏してください。

## 第三部：マイクポジショニング

### 1. 楽器とマイクの相対位置
- 録音時は、使用するマイクを音源の発音位置に直接または斜めに向け、同時にマイクをできるだけ音源に近づけて最適な直接音を得て、ルームリバーブやその他のノイズの割合を減らします。

### 2. 楽器別マイク配置ガイド

#### 🎤 ボーカル編
- **リードボーカル**：口からマイクまで約15～25cm（拳一つ分の距離）。近すぎると「近接効果」（低域過多、音がこもる）やポップノイズが発生し、遠すぎると環境騒音やルームリバーブを拾いすぎます。
- **バックボーカル**：機材がなければリードボーカルに準じてください。機材がある場合はステレオ録音ガイドを参照してください。

#### 🔌 エレクトリック楽器編
原則としてライン録音（DI）のみ受け付けます。プロ仕様のマイク、アンプヘッド・キャビネット、良好な音響環境を使用できる、明確なビジョンを持つプロの演奏者でない限り、マイク録音は避けてください。

- **エレキギター／エレキベース**：
  - ギタリストはデフォルトでオーディオインターフェース、エフェクター、DAWを使用して録音してください。
  - **パート別ドライ信号要件**：
    - 可能な場合：アンプヘッドのオーバードライブをかけたキャビネット音を1トラック、完全に無効果のドライ信号を1トラック、自身のアイデアによるエフェクト音を1トラック（同じ演奏の3トラック同時録音！3回の別テイクではありません！）
    - 不可能な場合：完全に無効果、またはオーバードライブとキャビネットシミュレーターのみのドライ信号1トラックのみで構いません。
  - **重要**：いかなる場合も、**リバーブ、ディレイ、フランジャーなどの空間系・モジュレーション系エフェクトが一切かかっていない**トラックを最低1つ確保してください！！！

- **電子ピアノ**：
  - **ライン録音**：スマートフォンのヘッドホン変換アダプタを使用して、キーボードのヘッドホン出力をスマートフォンのマイク入力に接続します。可能であれば、標準フォンケーブル1ペアでオーディオインターフェースとDAWに接続し、ステレオ録音することを推奨します。
  - **マイク録音**：ライン録音が不可能な場合は、スマートフォンをスタンドに固定し、キーボードのスピーカーに近づけて録音します。

- **電子ドラム（重要！）**：
  - 可能であれば、MIDIトラックを録音して書き出し、編曲者やミキシングエンジニアが音色を選択できるようにすることを強く推奨します。これにより各ドラムの個別パートが得られ、ドラムと他の楽器を最大限に融合させることができます。

#### 🎻 アコースティック楽器編
- **弦楽器**（ヴァイオリン、ヴィオラ、チェロ、コントラバス）：スマートフォンを楽器の斜め上方に置き、マイクをf字孔または指板と本体の接合部に向け、距離は約1～1.5m。弓と弦の接触点に直接向けると、摩擦ノイズを拾いすぎるため避けてください。
- **木管楽器**（フルート、クラリネット、オーボエ等）：スマートフォンを頭の高さに合わせ、楽器の中央部分に向け、距離は約1m。キーノイズと息の音のバランスが良好に録れるようにします。
- **金管楽器**（トランペット、トロンボーン、ホルン等、サックスも含む）：スマートフォンをベル（朝顔）の脇前方（約45度の角度）に配置し、ベルに向けて、距離は1.5～2m。音の歪み（過負荷）を防ぎます。
- **打楽器**：ティンパニ等は、スマートフォンを前方の一定距離に配置します。小物打楽器は、上記の距離原則を参考にしてください。
- **鍵盤楽器**（ピアノ、マリンバ、ヴィブラフォン等）：スマートフォンを音源の真前方の一定距離に配置します。可能であればステレオ収音方式のガイドを参照してください。
- **アコースティックギター**：
  - ピックアップがある場合は、オーディオインターフェースとDAWに接続して録音することを推奨します。
  - ピックアップがない場合：スマートフォンをギターよりやや高めに、ネックとボディの接合部（おおよそ12～14フレット付近）に向けて斜め下に、約30～50cm離します。これが最もバランスの取れた音で録れる位置です。
  - **注意**：スマートフォンをサウンドホールに正対させないでください！サウンドホールはギターの低音共鳴が最も強い場所であり、正対録音すると音がこもり、不明瞭な音になります。

### 3. 録音前の最終調整：歪み（クリッピング）テスト

**クリッピングとは？**
録音におけるクリッピング（専門的には「クリッピング歪み」）とは、音源の音量が録音機器の処理限界を超え、音声波形が「切り取られ」平らになり、「バチバチ」「パチパチ」という刺さるような、破れたような歪みノイズが発生する現象です。

**スマートフォンでのクリッピング防止方法**：
1. マイクと音源のおおよその位置を決めたら、テスト目的の録音を開始します。
2. 最大の強さで楽器を演奏し、可能な限り大きな音圧の音を出します。
3. 録音を終了し、音声に歪みがないか確認します。
4. 歪みがある場合は、マイクを約25cmから0.5mほど遠ざけます。
5. 歪みがなくなるまで上記の手順を繰り返します。
6. 同時にマイクと音源が角度（約45度）を持つようにします。

**プロ機器でのクリッピング防止方法（GarageBandやオーディオインターフェース使用時）**：
1. マイクと音源のおおよその位置を決めたら、最大の強さで楽器を演奏します。
2. ピークレベルがおよそ-6dBFS付近で推移するようにマイクのゲインを調整します。
3. これにより、演奏中のどのような強弱でも、レベルが最大0dBFSを超えてクリッピング歪みが発生することがなくなります。

### 4. 統一された開始・終了の合図（「カチンコ」）
- **開始合図**：録音開始後、カメラに向かって、手を叩く、指を鳴らす、「3、2、1、録音開始！」と大声で言うなど、音のアタックが速く明確で明瞭な合図を出してください。これによりポストプロダクションでの映像と音声の同期が容易になります。
- **終了後の静止**：演奏終了後、姿勢を保ったまま5秒程度静止してから録音を停止してください。これによりノイズリダクションに必要な貴重な環境ノイズサンプルが得られます。

### 5. 録音終了後
- ヘッドホンを装着し、録音を最初から最後まで完全に聴き直します。
- リズム、音程、段落などの間違いがないか確認します。もしあれば、十分に練習を重ねた上で再録音してください。
- ポップノイズやクリッピングなどの音声品質の問題がないか確認します。もしあれば、マイクの距離を調整して再録音してください。
