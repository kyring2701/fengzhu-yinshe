# 🍃 楓竹音社について

ここは楓竹音社です。

ここでは、レベルに上下はなく、趣味に制限もありません。楽理に精通する必要も、優れた技術を持っている必要もなく、ただ音楽への熱意さえあれば、この終わりのない音律の饗宴に共に赴くことができます。

楓竹音社は創立以来、一年以上にわたり安定して運営されており、現在のメンバーは百五十名余りです。コミュニティの雰囲気は包摂的で多様性に富み、人材層も豊かで、長年音楽に携わり卓越した技術を持つプロの先輩が陣頭指揮を執り導く一方で、熱意に満ちゼロからスタートした初心者も夢を追いかけて共に歩んでいます。

当社はオンライン音楽協同コミュニティであり、柔軟で自由な創作・コラボレーションモデルを備えています。メンバーは自由にコラボ企画を発起し、自主的に演奏曲を選定し、自由にチームを組んで編曲・表現することができ、オフラインの時空の制約を受けず、演奏レベルの制限もありません。コミュニティの曲風は兼容並蓄で、これまでにJPOP、JROCK、吹奏楽など多様なジャンルの作品の上演に成功し、成熟したオンライン合奏、パート別録音、ポストプロダクション経験を蓄積してきました。

今後、音社は既存の創作基盤をもとに、すべての同好の士の参加と共創の下で、曲風の境界を持続的に拡大し、より多くの音楽分野を探求し、自由度が高く、包摂性が強く、専門性を兼ね備えたオンライン音楽交流プラットフォームを築き上げていきます。

弦が鳴り始めれば、婉曲に流れ、
管が鳴る時は、壮大に響き渡り、
鼓が韻を打てば、リズミカルで力強く、
声が調和すれば、清らかで空靈。
音を契りとし、音を友として、共に高山流水の友となり、共に管弦の調べを楽しみましょう。
