# 📋 云合奏指南

> 致各位演奏家

乐团成员们，大家好！

为了让我们分布在不同地方的演奏，能够汇聚成一首和谐动人的交响乐，高质量的原始录音至关重要。请不要担心，您不需要任何专业设备，只需要您的手机和一点点耐心。请务必仔细阅读并遵循以下指南，这将为后期的混音师节省大量的时间，并直接决定我们最终作品的质量。

---

## 写在开头：一些关于混音师的建议

1. **音准和节奏**是每位乐手和演奏家最基本的基本功，是乐团里最基本的要求也是最重要的要求。对于线上云合奏来说，任何错拍或者跑音更是会被无限放大。因此在录制中，请听准节拍器，确保演奏的每一拍都在节拍上。对于一些渐快渐慢的自由节奏，可以由编曲师和乐手们商量好之后，用宿主画出速度轨的自动化，再导出完整的节拍器音频，让乐手们对着定制的节拍器音频练习。同时，尽量减少多支乐器共同演奏跑动音的编写；尽量由基本功扎实优秀的乐手来承担主旋律和带有大量快速跑动音符的演奏；尽量商量好弱起、休止延长、音尾和跑动音等的具体时值，以确保弱起之类的音头音尾能对齐。

2. **尽量不要分段录制**，能从头到尾一遍过最好一遍过。如果实在没办法需要分段录制，请明确给出该段的具体信息：如给文件修改命名（标注小节数，第几到第几小节）、在录制开头或结尾用口播说出该段的小节数等方法，以方便后期校对段落。

## 第一部分：录音前的准备

### 1. 选择一个安静的房间
- 尽可能关闭所有可能发出噪音的电器（空调、风扇、冰箱、手机铃声）
- 确保房间内的门窗已关严，以减少车辆、风声等环境噪音
- 提前告知家人或室友，确保在录音期间不会被打扰

### 2. 确保干声"干"
- 避免在空旷、充满回声的房间里录音（例如未装修的客厅、洗手间）。回音是录音的"头号杀手"，后期很难去除
- **最佳地点**：卧室、书房、或有较多家具、窗帘、地毯的客厅。这些柔软的物体可以有效吸收回声，让你的声音更干净。对着衣柜或挂满衣服的地方录音也是个好办法！
- **应急方案**：假如实在没办法，必须强制在空旷的会造成大量房混的房间内录制。可以尝试将房间内所有不会造成共振的杂物堆放在一个角落，然后背靠着杂物演奏，同时将麦克风尽量靠近声源，由上至下对准琴体，这样能最大程度录制出最干净的直达声

### 3. 固定好手机
- 不要手持手机录音，手部微小晃动会影响声音
- 建议使用手机三脚架、桌面支架等，或者将手机靠在几本书上，确保它稳定不动

### 4. 使用统一的标准音
- 总负责人会指定标准音A的频率。确保你的乐器音高是正确的，也可以在曲子前后都演奏一段这个标准音，方便后期校对音准

## 第二部分：录音设置

### 1. 确保麦克风清洁程度
- 录音前，检查手机麦克风是否干净整洁，有无灰尘堵塞，若有可以适当用牙刷毛刷或细头棉签等轻微擦拭麦克风

### 2. 了解手机麦克风位置（以苹果手机为例）
- **手机底部**：在手机的底部、充电口和扬声器旁，通常会有一到两个麦克风。手机自带的语音备忘录、一般的录音软件、打电话开启免提时都会使用此侧的麦克风
- **手机背面**：在手机的背面，摄像头与LED闪光灯之间通常会有一个小孔，这就是后置麦克风。一般是使用后置摄像头录制视频时会使用此侧麦克风
- **手机屏幕上方**：在iPhone的手机屏幕上方、听筒附近通常会隐藏着一个麦克风。使用前置摄像头录制视频、进行视频通话时会使用此侧麦克风

### 3. 调整手机设置
- 有必要的话，建议**开启飞行模式**。这可以防止一个突如其来的电话或通知音毁掉你最好的那次录音

### 4. 使用高质量的录音App
- 不建议使用手机自带的语音备忘录或随处下载的"录音机"软件，除了本身录制质量低以外，它们通常会为了文件体积而牺牲音质
- **推荐App**：
  - Shure MOTIV Audio（iOS/Android）
  - Garage Band库乐队（iOS）
  - 它们能录制无损格式

### 5. 设置音频格式、采样率和比特率
能设置的，请统一设置为：
- **格式**：wav
- **采样率**：48000kHz（最低不低于44100kHz）
- **比特率**：24bit（最低不低于16bit）
- **声道数**：单声道/立体声

### 6. 耳机和节拍器
- 使用另一部手机或者是能连接耳机的节拍器连接封闭式耳机，并带上耳机，在耳机中以指定的速度播放节拍器演奏

## 第三部分：麦克风摆位

### 1. 乐器与麦克风的相对位置
- 在录音时，尽量将当前采用的麦克风直指或侧向对准音源发声位置，同时尽量将麦克风尽可能地靠近声源以获得最佳直达声，减少房混和其他杂音的比例

### 2. 不同乐器的麦克风摆放指南

#### 🎤 人声篇
- **主唱**：嘴巴离麦克风约15-25厘米（一个拳头的距离）。太近会产生"近讲效应"（低频过多，声音浑浊）和喷麦声；太远会拾取更多环境噪音和房间混响
- **伴唱**：没条件的参考主唱即可，有条件的参考立体声录制指南

#### 🔌 电声篇
原则上只接受内录，尽量避免外录，除非你是有自己想法的专业乐手，能使用专业麦克风、箱头箱体以及拥有不错的声学环境

- **电吉他/电贝斯**：
  - 默认各位吉他手都会使用声卡、效果器和宿主进行录音
  - **分轨干声要求**：
    - 有条件的：录制一轨带箱头过载的箱体声音、录制一轨完全无任何效果的干声、录制一轨有自己想法的带效果器的声音（用三条轨道录制同一次演奏！不是录三遍！）
    - 没条件的：只需要一轨完全无任何效果或只带过载和箱模的干声即可
  - **重要**：无论如何，请确保有一轨是不带任何混响、延时、镶边等空间和调制类效果器的！！！

- **电钢琴**：
  - **内录**：使用手机的耳机转接线，将键盘的耳机输出连接到手机的麦克风输入。有条件的，建议使用一对大二或大三芯线连接声卡和宿主进行立体声录制
  - **外录**：如果无法内录，可以将手机固定在支架上，靠近键盘的扬声器进行录制

- **电鼓（重要！）**：
  - 有条件的，非常建议录制midi轨导出，让编曲或后期老师来挑选音色，这样能得到各个鼓的具体分轨，能最大程度地使鼓和其他乐器融合

#### 🎻 原声篇
- **弦乐器**（小中大倍大提琴）：手机应放在乐器的斜上方，麦克风指向f孔或指板与琴身的连接处，距离约1-1.5米。避免直接对准弓弦交接处，以免录下过多的摩擦噪音
- **木管乐器**（长笛、单簧管、双簧管等）：手机应与你的头部高度持平，指向乐器的中间部分，距离约1米。确保能清晰地录到按键声和气息声的平衡
- **铜管乐器**（小号、长号、圆号等，萨克斯也算）：将手机放在喇叭口的侧前方（约45度角）并对准喇叭口，距离1.5-2米，以防止声音过载失真
- **打击乐**：如果是定音鼓等，手机放置在鼓前方一定距离即可。如果是小打，参考上述距离原则
- **键盘类**（如钢琴、马林巴、颤音琴等）：将手机放置在声源正前方一定距离即可。有条件的最好参考立体声制式录音指南
- **木吉他**：
  - 有拾音器的，建议连接声卡和宿主进行录制
  - 没有拾音器的，手机略高于吉他，斜向下指向琴颈与琴箱的连接处（大致在12-14品的位置）约30-50厘米。这是平衡度最佳的位置
  - **注意**：不要将手机正对音孔！音孔是吉他低频共鸣最强的地方，正对录制会导致声音浑浊发闷

### 3. 录制前的最后调整：测试失真爆音

**什么是爆音？**
录制中的爆音（专业上称为"削波失真"），是指声源的音量强度超过了录音设备所能处理的极限，导致声音波形被"削平"，从而产生一种刺耳、破碎的"噼啪"或"撕裂"的失真噪音。

**手机录音防爆音方法**：
1. 确定好大概的麦克风和声源位置后，开始一次以测试为目的的录制
2. 用最大力度演奏你的声源，想办法让它发出一个最大声压级的声音
3. 结束录制并检查音频是否出现失真
4. 若有失真，请将麦克风拿远大概25厘米到半米左右
5. 重复上述步骤直至音频不再出现失真
6. 同时确保麦克风和声源呈一个夹角（大概45度左右）

**专业设备防爆音方法（使用库乐队或声卡）**：
1. 确定好大概的麦克风和声源位置后，用最大力度演奏你的声源
2. 调整麦克风的增益直至电平峰值大概在-6dBFS上下浮动
3. 这样无论你在演奏中使用怎样的力度，电平最大都不会超过0dBFS以产生削波失真

### 4. 统一的开始和结束信号（即"打板"）
- **开始信号**：开始录制后，请在镜头前给一个音头快速、明确、清晰的信号，例如拍掌或是打个响指，或是大声说出"三、二、一，录制开始！"，方便后期视频和音频的对轨剪辑
- **结束静止**：演奏结束后，保持姿势静止5秒左右再停止录制。这能为后期降噪时提供宝贵的环境噪音样本

### 5. 录制结束后
- 请带上耳机，从头到尾完整地听一遍录音
- 确保没有吹错节奏、音准、段落等问题，若有，请在确保练习充分的情况下重新录制
- 确保没有喷麦爆音等音频质量问题出现，若有，请调整麦克风距离并重新录制
