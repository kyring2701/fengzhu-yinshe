# 🎹 曲目推荐

有想演奏的曲子？来这里推荐你心仪的曲目，让大家一起合奏！

## 📝 如何推荐

1. 点击下方链接，打开曲目推荐表
2. 填写曲目名称、原作者、风格类型
3. 简单描述你为什么想演奏这首曲子
4. 提交后，我们会根据大家的选择来安排项目！

## 🎵 推荐要求

- 曲风不限：ACG、吹奏乐、管弦乐、摇滚、爵士都欢迎
- 难度不限：从简单的小合奏到大型编制都可以
- 版权注意：我们仅作非商业性合奏练习
